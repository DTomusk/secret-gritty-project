# secret-gritty-project
The nature of this project is on a need-to-know basis, and I'm the only one who needs to know. 

## Stack
- .Net 10 C# backend
    - Separate API and Worker deployables 
    - Common domain, application and infrastructure layers (CLEAN architecture)
- React frontend 
    - rhf forms 
    - MUI component library 
    - Tanstack react query 
    - fetch for API requests 
- Dockerfiles for API and Worker
